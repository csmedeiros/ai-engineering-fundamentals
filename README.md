# Curso 1 — Fundamentos de AI Engineering

Material e demos do curso **Fundamentos de AI Engineering** (YouTube / programa educativo).

## Diretrizes

- **Vanilla:** chamadas diretas à API do LLM, sem framework
- Frameworks e evals ficam para cursos avançados
- Cada episódio mostra a limitação antes da técnica

## Estrutura (visão geral)

1. Tokens, embeddings e atenção
2. Workflows (pipeline sequencial)
3. Memória e histórico de contexto
4. Janela deslizante com seleção inteligente
5. Tool calling (busca na web)
6. RAG 01 — a limitação
7. RAG 02 — chunking + similaridade
8. RAG 03 — RAG agêntico
